 •• "Вятка" желает перекраситься


 
Кировская дирекция по обслуживанию пассажиров в дальнем сообщении
объявляет конкурс для дизайнеров на лучший внешний вид фирменного
поезда "Вятка" - визитной карточки Кировской области.

При разработке цветовой гаммы нового облика поезда допускается
использование только двух оттенков. Экспертное жюри, состоящее из
руководителей Кировской дирекции по обслуживанию пассажиров в дальнем
сообщении, оценит конкурсные работы и выберет победителя. Его
дизайнерская разработка будет использована в перекраске поезда
"Вятка".

Полную информацию о конкурсе можно узнать по телефонам: 60-22-54,
60-20-29 - инструкторы резерва проводников. Работы на конкурс
принимаются по адресу: ул. Комсомольская 46 - 3 этаж (резерв
проводников).
