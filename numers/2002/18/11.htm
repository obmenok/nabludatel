Отныне садоводы и огородники, а также фермеры могут рассчитывать на
увеличенные земельные наделы. В их пользу областной Думой приняты
два закона: "О предельных размерах земельных участков,
предоставляемых гражданам в собственность в Кировской области" и "О
максимальных размерах бесплатно предоставляемых в собственность
граждан земельных участков"

Согласно первому, устанавливаются предельные (максимальные и
минимальные) размеры земельных участков, предоставляемых гражданам для
ведения садоводства, огородничества, для дачного строительства, а
также ведения крестьянского (фермерского) хозяйства. В последнем
случае будущий фермер может рассчитывать на 50 га (максимальная норма)
- на таком участке уже реально завести рентабельное хозяйство.
Самые заядлые садоводы и огородники под свои смородины-крыжовники,
огурцы-помидоры, картошку-капусту смогут получить по 0,15 га.

Второй закон устанавливает максимальные нормы )бесплатного(
землепользования, которые составляют:

- для ведения фермерского хозяйства - 8 га;

- для ведения садоводства - 0,10 га;

- для ведения огородничества - 0,10 га;

- для ведения дачного строительства - 0,04 га;

- для ведения личного подсобного хозяйства - 0,15 га;

- для индивидуального жилищного строительства - 0,15 га.

В обиде остаются животноводы: для них законопроект не предусматривает
бесплатный участок максимального размера. Реализация этой нормы
откладывается до принятия федерального закона об обороте земель
сельскохозяйственного назначения. В какой-то мере отсутствие в законе
отдельной "животноводческой" статьи компенсируется бесплатным
предоставлением участков для личных подсобных хозяйств.
