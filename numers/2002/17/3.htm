Hомер 17 за апрель 2002 года.

 •• Для автобусов наступило лето


 
Распоряжением администрации города Кирова с 1 мая 2002 года введен в
действие "План выпуска автобусов и троллейбусов на маршруты города
Кирова на летний период 2002 года".

С 1 мая по 6 октября 2002 года будет организована работа экспрессного
автобусного маршрута N 29 по трасс: Макарьевское кладбище - ул.
Проезжая - ул. Профсоюзная - Октябрьский проспект - ул. Дзержинского -
новый мостовой переход через реку Вятка - сады "Надежда" (с выполнением
посадки и высадки пассажиров на следующих остановках общественного
транспорта: "Макарьевское кладбище". "АЗС", "Улица Свободы", "Центр
детского и юношеского творчества","Областной дом народного творчества",
"Площадь имени Лепсе", "Улица Дзержинского", "Поселок Силикатчик",
"Сады "Черное озеро", "Сады "Надежда".

С 18 мая 2002 года автобусный маршрут N 12 будет следовать по маршруту:
от улицы мира до железнодорожного вокзала - по существующему маршруту -
далее по улице Комсомольской - улице Мельничной - улице деповской -
улице Украинской - Учхоз - Цыганы с сохранением действующего на маршруте
интервала.

С 1 мая 2002 года:

- изменен маршрут автобуса N 3: Милицейская - Ленина - Профсоюзная - П.
Корчагина - поселок Домостроителей. Ежедневно каждый второй рейс маршрута
N 3 продлен до остановки "Черное озеро". Автобусам, выполняющим эти
рейсы присвоен номер N 3"А".

- открыт маршрут N 33 по трассе: площадь завода "Авитек" - новый
мостовой переход через реку Вятка - улица Павла Корчагина - площадь
Коминтерн.

- закрыт автобусный маршрут N 2.

- автобусный маршрут N 44 будет направлен от Ипподрома через поселок
Мирный по улице Ульяновской - улице Щорса - улице Попова - улице
Некрасова - улице горького - железнодорожный вокзал - Комсомольская
площадь.

- будет организовано по выходным дням выполнение двух утренних и двух
вечерних рейсов сезонного (летнего) экспрессного маршрута N 55Э по
трассе "Улица Милицейская - Лесная полянка" с остановками "Филармония",
"Герцена". "Магазин "Мелодия", " Мопра", "Профсоюзная", "АЗС",
"Порошинский поворот", "Порошино", "Лесная полянка".

- по рабочим дням два утренних и два вечерних рейса до ООТ "Лесная
полянка" будут выполнять автобусы 21 маршрута.

- будет организована работа маршрута N 14 по трассе: ООТ "Спичфабрика
"Красная звезда" - улица Профсоюзная - улица Ленина - ООТ
"Милицейская" (диспетчерская).

С 18 мая 2002года будет закрыт маршрут N 11.
