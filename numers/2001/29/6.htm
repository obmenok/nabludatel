 •• Ветераны: проезд по новым правилам


 
С 1 августа 2001 года порядок предоставления бесплатного проезда в
городском общественном транспорте приводится в соответствие с
Федеральным законодательством.

1. Основанием для предоставления бесплатного проезда для ветеранов
труда является удостоверение единого образца, выдаваемое в
соответствии с Федеральным законом "О ветеранах" органами социальной
защиты по месту жительства. Ранее действовавший временный порядок
предоставления бесплатного проезда ветеранам труда по пенсионным
удостоверениям со специальным штампом "Ветеран труда" отменяется. Для
ветеранов военной службы, ветеранов государственной службы порядок
предоставления бесплатного проезда остается прежним.

2. Именной талон-вкладыш (с зеленой полосой) действителен для
бесплатного проезда только при предъявлении вместе с одним из
следующих удостоверений:

"Удостоверение участника войны" для участников Великой Отечественной
войны).

"Удостоверение о праве на льготы" (для лиц награжденных орденами и
медалями СССР за самоотверженный труд в тылу в годы Великой
Отечественной войны).

Пенсионное удостоверение со штампом "Вдова (мать, отец) погибшего
воина" или соответствующей записью, заверенной печатью и подписью
руководителя учреждения, выдавшего указанное удостоверение.

Указанные документы действительны при проезде и без именного
талона-вкладыша (с зеленой полосой).
