 Кировские выпускники сдадут математику по новым правилам


С 2003 года Кировская область включилась в общероссийский
образовательный эксперимент по единому государственному экзамену
(ЕГЭ). В нем примут участие выпускники одиннадцатых классов 485
средних и пяти частных школ, а также лицеев и гимназий.

ЕГЭ дает возможность сдать выпускные экзамены по отдельным предметам,
результаты которых будут одновременно учитываться в аттестате и при
поступлении в вузы. В Кировской области ЕГЭ для всех станет математика,
а из предметов по выбору биология и химия. Остальные школьные
дисциплины будут сдаваться привычным для всех образом - по билетам.

Запланированные вначале сроки сдачи ЕГЭ для выпускников средних школ
с начала перенесли на конец мая. А те, кто получили аттестат раньше,
будут сдавать ЕГЭ после 15 июля. Единый экзамен сдается только раз в
год. Повторно испытать судьбу можно в июльском потоке следующего года.

Репетиция ЕГЭ по математике пройдет для всех учеников в один день
уже в апреле. Экзамен будет сдаваться не в родной школе, и шанса, что
одноклассники окажутся за соседними столами не представится - их
рассадят по разным кабинетам. Математику будут сдавать четыре часа
(на химию и биологию отведут на час меньше).

С заданиями, которые поступят из Москвы в пакетах индивидуального
открытия, ученики познакомятся прямо на экзамене. Их будет три: тест
(А) и творческое решение задач (В,С). Для решения упражнений запрещено
пользоваться формулами, раздаточными материалами и даже калькуляторами.

По истечении четырех часов работу запечатают в пакет индивидуального
закрытия. На работе не будет ни фамилии ученика, ни номера - ее
обозначат штрих-кодом. Ответы сканируются в области, а затем под
охраной отправят в Москву для проверки.

Оценивать работу будут по стобальной шкале, которая даст объективную
картину знаний. Любая "традиционная" оценка ученика по сути разная не
только в двух школах, но и в двух классах, потому что содержит
субъективное мнение преподавателя. Новая для России система оценки
знаний общепринята во всех странах Европы, поэтому результаты ЕГЭ будут
признаны за границей. До эксперимента с единым экзаменом наши аттестаты
"за бугром" цены не имели.

Из кировских вузов результаты ЕГЭ согласны принимать Вятский
государственный университет и Вятский государственный гуманитарный
университет. Поступая в эти вузы, по ЕГЭ можно сдать математику,
биологию и химию. Принимать таким же образом физику и математику они
отказались.

Медакадемия отказалась учитывать результаты ЕГЭ по химии и биологии.
Вятская государственная сельскохозяйственная академия на ряд
специальностей будет принимать выпускников по единому экзамену, но этот
ряд пока не определен.

Негосударственные вузы, государственные и коммерческие средне-специальные
заведения в приеме выпускников по ЕГЭ не отказывают.

   Инна ШЕЛЕХОВА

 •• Зачем вводить ЕГЭ


Единый госэкзамен поможет обеспечить равные условия для всех
абитуриентов при сдаче выпускных экзаменов в школе.

Такой контроль знаний позволяет разгрузить выпускников-абитуриентов,
чтобы не приходилось сдавать один экзамен дважды.

Благодаря ЕГЭ расширятся возможности для поступления в вузы
способных детей из дальних регионов в Москву и другие крупные города.
